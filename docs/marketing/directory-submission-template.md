## Standard Submission Block

**Name:** Humanity4AI (project_human)

**Short Description (1 sentence):**  
Open-source collection of 9 rule-based "humanity skills" for AI agents — crisis detection, WCAG 2.2 auditing, empathetic reframing, cultural sensitivity, and more — MCP + npm.

**Full Description (150 words):**
Humanity4AI is an open-source skill system that gives AI agents reusable, tested behaviors for humane interaction. Nine skills cover emotional safety (crisis detection + supportive replies, depression-sensitive content rewriting), accessibility (full WCAG 2.2 audit across all 86 success criteria), cognitive accessibility, cultural sensitivity, conflict de-escalation, empathetic communication, neurodiversity-aware design, and age-inclusive design. All skills are rule-based — zero LLM calls — with explicit safety boundaries, uncertainty disclosure, and structured JSON-schema-validated outputs. Available as a remote MCP server at `humanity4ai.ascent.partners/api/mcp` (no install needed) or via `npx @humanity4ai/mcp-servers`. 9 languages, 90%+ test coverage, MIT licensed.
